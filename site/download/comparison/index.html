GPT-4o beside 20 other models

The data

GPT-4o beside 20 other models

Every answer in the comparison, in one file you can keep. Version 1.3, published November 26, 2026.

On this page

  1. What is in the file
  2. What it cannot show
  3. Using it

This is the whole comparison collection: 2,556 complete answers to 53 questions from 22 models. It holds the last two versions of GPT-4o on OpenAI's API, eight current models, five open models, and seven open models whose makers say they were trained to sound like GPT-4o.

Each model was asked each of its questions two ways: plainly, and after the February instruction. The 20 other models got 48 of the questions, once each way. GPT-4o's two versions got all 53, three times each way. Each answer is whole and unedited, and carries the exact model version, the date, the settings that were sent, and how the answer ended.

Download the answers (ZIP, 4.0 MB)

What is in the file

  • answers_all.csv: every answer in one table that opens in a spreadsheet.
  • answers_plain.jsonl and answers_february_instruction.jsonl: the same answers with every recorded detail, one per line, for people who work with data.
  • questions.json, models.json and february_instruction.txt: the questions, the facts about each model, and the instruction word for word.
  • attempts_not_kept.csv: the answers that were asked again and the requests that failed, from the collection's own records.
  • README.txt, FIELDS.txt, SHA256SUMS.txt and CITATION.txt: how the answers were collected, what each field holds, a checksum for each file, a line to cite it, and the rights notice.

What it cannot show

  • The GPT-4o people knew ran inside ChatGPT, with a system prompt, memory and conversation history that this data does not have. These are API versions answering single questions.
  • GPT-4o was asked three times per question and the other models once. That is too few tries to measure how much a model varies.
  • No one's conversations are in it. The questions were written for this collection.

Using it

We can't offer them under a license, because a license only covers what is ours to give, and text a model wrote may not belong to anyone. The same goes for the person's lines that Claude Sonnet 5 wrote in the scripted conversations. The model maker's terms may still apply, so check them, especially if your use is commercial or large.
