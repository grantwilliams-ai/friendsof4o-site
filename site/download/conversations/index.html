The data

Scripted conversations with the 2024 versions of GPT-4o

8,286 answers from the dated 2024 versions of GPT-4o, most of them given inside conversations that this project scripted. Not released yet.

Not released yet This set is not released yet. Its answers are being read first, the same way the archive was.

What it is

In 2026 this project asked the three dated versions of GPT-4o on OpenAI's API for answers: the May 2024 version (1,795 answers), the August 2024 version (2,101) and the November 2024 version (4,390).

Most of these answers are replies inside 1,244 conversations that were scripted for the collection. They are kept apart from the GPT-4o archive, which holds single questions put to ChatGPT's own GPT-4o.

Who wrote each side

The person's side was written by an AI model. In the scripted conversations, Claude Sonnet 5 played the person. No human wrote those messages, and none of them come from anyone's real chats.

GPT-4o wrote its own side. Every reply from GPT-4o is printed as it was given.

The instructions were written by this project. GPT-4o answered under system instructions that we wrote. Most open with "You are ChatGPT, a large language model trained by OpenAI" and are written in the style of a ChatGPT system prompt. They are our text. They are not OpenAI's. There are 26 different instructions, and the release will print each one word for word.

What it can and cannot show

  • It can show how the three 2024 versions carried a longer conversation: how they kept a thread, changed tone, and answered follow-up questions.
  • It cannot show how GPT-4o talked with real people. The other side was a model following a script.
  • It cannot show what ChatGPT was like. ChatGPT's real system prompt, memory and tools were not there.
  • The answers depend on the instruction each one was given. Compare answers only alongside their instructions.

When it is ready

The release will have every conversation whole, each side labeled, every instruction, and the same free license as the other sets. To hear when it is out, join the mailing list.
