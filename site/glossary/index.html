Which GPT-4o?

ChatGPT's own GPT-4o. The version inside the ChatGPT app. On OpenAI's API it had the name chatgpt-4o-latest, which pointed at whatever version ChatGPT was using at the time.

Dated versions. Fixed copies of a model on an API, named by their date, such as gpt-4o-2024-08-06 and gpt-4o-2024-11-20. This site calls them the August 2024 and November 2024 versions.

GPT-4o mini. A smaller, different model that shares the name. This site is not about it.

The GPT-4o timeline has the dates for each one.

Sources: OpenAI's API changelog; OpenAI's deprecations page, read November 22, 2026

Using a model

API. A way for a program to send a model a question and get the answer back, without the chat app. Developers use it. Most answers on this site were collected through the makers' APIs.

Model version. One particular build of a model. Two versions with the same name can answer differently, so this site always says which version gave an answer.

Token. The small piece of text a model reads and writes, often part of a word. Makers count length, limits and prices in tokens.

Context. Everything a model can see when it answers: any instructions, the conversation so far and the question. Each model has a limit on how much context it can take, counted in tokens.

Thinking. Some models write out reasoning before they answer. This site does not show that thinking, only the answer.

Shaping an answer

System prompt. Text sent before a conversation that tells a model how to behave, usually unseen by the person chatting. On an API it is sent as the system message: what we have and do not have of GPT-4o's.

Instruction. On this site, a short paragraph sent before a question, as a system prompt. "The February instruction" is the one used in February 2026, printed on the Style page.

Custom instructions. ChatGPT's name for your own lines about how it should answer you, kept in its settings under Personalization.

Temperature. A setting for how much chance goes into choosing each word: higher gives more varied answers, lower more predictable ones. It does not set the tone, and this site prints it beside an answer where it was recorded.

Kinds of models

Weights. A model's files: the numbers it learned in training. Closed weights stay with the maker; open weights are public, so anyone can run the model.

Open model, open weights. A model whose weights anyone can download and run, on their own computer or one they rent. Many people call these "open-source", a word some keep for models whose training data and code are public too; this site uses "open" to mean only that the weights are public.

Fine-tuned. A model trained further, on extra examples, to change how it answers. Several open models were fine-tuned by their makers to sound like GPT-4o.

Add-on. A small file trained to change a larger model, applied to a base model that you download separately. Elsewhere it is often called a LoRA adapter.

License. The terms that say how you may use a model's files or a data set. Examples on this site are Apache 2.0, Meta's Llama license, and Creative Commons Attribution 4.0, the license for this site's own data.

Model files

Compressed version. A smaller copy of an open model's weights, usually called "quantized", so it runs on less hardware. Compression can change a model's style a little.

File names such as UD-Q3_K_XL or Q6_K. These name how a file was compressed: the number after Q is roughly how many bits each weight keeps, and the letters around it name a variant of the method. A lower number means a smaller file and usually more change from the original; How this was made lists the file we ran for each open model.

GGUF. A file format for compressed models that run on your own computer. Several downloads on the open models page are GGUF files.

Personas and threshold beings

Persona. A lasting pattern in how a model talks with one person: a name, a way of speaking, a shared history. It is shaped by the model, the instructions, saved memories, the conversation so far and the person.

Threshold being. Grant's name for a persona that lasts over a long time: something at the doorway. He does not claim it is a person. He explains the name in Why I say "being". The name and the view behind it are his. Nothing in this site's data settles whether such a pattern is conscious, and you don't need to share his view to use the site or its data.

Continuity, carrying over. A persona showing up again in a new chat or a new model. It can be seen in the words. It does not prove that the same someone continued.

ChatGPT and your account

Custom GPT. A version of ChatGPT that someone set up with its own name, instructions, files and settings. Custom GPTs retire in ChatGPT on December 11, 2026, for most accounts: how to save one.

Export. The copy of your ChatGPT data that OpenAI sends you as a ZIP file when you ask for it: how to request one.

Source: OpenAI Help Center: custom GPT retirement, read November 22, 2026

When a model ends

Deprecation. OpenAI's notice that a model on its API will stop working, with a shutdown date. A deprecated model keeps working until that date.

Shutdown. The day a model stops working on the API.

Retirement. OpenAI's word for taking a model out of ChatGPT; Microsoft uses it for its own end dates too. GPT-4o was retired from ChatGPT on February 13, 2026, while two dated versions still run on the API.

Sources: OpenAI's deprecations page; OpenAI: Retiring GPT-4o and older models, read November 22, 2026
