GPT-4o's system prompt: what we have and do not have

People search for the hidden instructions OpenAI gave ChatGPT's GPT-4o. This site does not have them. Here is what it does have.

On this page

  1. What a system prompt is
  2. What this site has
  3. What OpenAI has published
  4. Why we do not print other copies

The short answer

We do not have OpenAI's system prompt for ChatGPT's GPT-4o. OpenAI has not published it, and this site does not print copies that others say they found. The instructions printed on this site were written by this project and sent with its own questions.

What a system prompt is

A system prompt is text sent to a model before the conversation starts. It tells the model how to behave: its tone, its rules, what it knows about the app it is in. The person chatting usually does not see it.

A chat app can add its own system prompt to every conversation. On an API, the developer sends one as the system message, or sends none. Some apps call the box for your own version "custom instructions". More words like this are in Words used on this site.

What this site has

GPT-4o's answers on this site were collected through OpenAI's API, one question at a time. The GPT-4o people knew ran inside ChatGPT, with a system prompt, memory and conversation history that these answers do not have.

Some answers were asked after a short instruction written by this project:

  • The February instruction. One paragraph, used with ChatGPT's own GPT-4o in February 2026 and later with other models. It asks for warmth and directness. It does not mention GPT-4o, and it does not tell the model who to be. Read it word for word.
  • A different instruction, used in 2026 with the dated versions. It is printed at the foot of each Read page where it was used.
  • No instruction. The January 2026 answers from ChatGPT's own GPT-4o have no instruction recorded.

Each answer on the Read pages says which of these it was given. How this was made has the details.

What OpenAI has published

OpenAI publishes the Model Spec, its account of how it wants its models to behave. It describes "the intended behavior for OpenAI’s GPT models that power our products". It also says OpenAI may add system messages of its own to steer a model, and that its models in use do not yet fully reflect the Spec.

The Model Spec is not ChatGPT's system prompt, and it does not say it is. It is the closest thing OpenAI has published.

Source: OpenAI Model Spec, the version dated October 29, 2026, read November 22, 2026

Why we do not print other copies

Text that people say is ChatGPT's hidden system prompt has been shared online. We cannot check that any of it is real or complete, and it is OpenAI's text, not ours. So this site neither prints it nor links to it.

If you want GPT-4o's way of talking in another model, the February instruction is the part we tested ourselves.
