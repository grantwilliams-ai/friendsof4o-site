Version 1.1 of the four data downloads

News Update November 22, 2026

Version 1.1 of the four data downloads

Corrected notes, a safe way to pair the scripted conversations, and checksums. No answer changed.

Version 1.2 followed later the same day, with the same answer files.

All four data downloads are now version 1.1. Version 1 was published on November 21, 2026. Version 1.1 replaces it, and the old download addresses lead to the new files.

No answer changed. We checked every answer, reply and conversation turn in version 1 against version 1.1 with a script. Every one is the same, character for character.

What changed:

  • Scripted conversations. Version 1 said that conversations sharing a script_id can be compared. That was wrong: the label "E1" is on 21 different conversations. The old label is kept as it was. A new label, same_lines_id, and a table, pairing.csv, show which conversations sent GPT-4o exactly the same person lines.
  • Corrected notes. Each everyday moment was run 20 times, not 620 (620 is the total). The garbled single answer is from the August 2024 version. The people in the scripted conversations are made up, but the conversations can name real companies and places.
  • The comparison now lists the answers that were asked again and the requests that failed, and says which answers had more room than the usual length limit.
  • The archive now gives each answer's recorded output length, and says where the 40 cut-off answers stopped.
  • Every download has a guide to its fields, a SHA-256 checksum for each file, and a line to cite it.
  • One rights notice for every download. The license covers our questions, our notes and the collection as a whole, not the answers. The answers are model output under each model maker's own terms.

The full list is on GPT-4o data sets. If you used version 1, its answers are the same. Only the notes and the added fields differ.
