Which GPT-4o?

ChatGPT's own GPT-4o
The version inside the ChatGPT app. On OpenAI's API it had the name chatgpt-4o-latest, which pointed at whatever version ChatGPT was using at the time. It left ChatGPT on February 13, 2026 and the API on February 17, 2026.
The dated versions
Fixed copies on OpenAI's API, for developers: May 2024 (gpt-4o-2024-05-13, shut down on October 23, 2026), August 2024 (gpt-4o-2024-08-06) and November 2024 (gpt-4o-2024-11-20). The last two run until January 14, 2027.
The voice models
Separate models for speech, gpt-4o-audio and gpt-4o-realtime, on their own schedule. They run on OpenAI's API until January 20, 2027.
GPT-4o mini
A smaller, different model that shares the name. This site is not about it.

2024

  1. May 13, 2024

    OpenAI releases GPT-4o

    OpenAI said the “o” stands for “omni”: one model that takes text, audio and images. Text and images started in ChatGPT, including the free plan, and in the API.

    Source: OpenAI: Hello GPT-4o

  2. May 19, 2024

    OpenAI pauses the voice called Sky

    Listeners had compared it to Scarlett Johansson. OpenAI said Sky was a hired actor's voice, not an imitation.

    Source: OpenAI: How the voices for ChatGPT were chosen

  3. August 6, 2024

    The August 2024 version arrives on the API

    Its API name is gpt-4o-2024-08-06. It is one of the two versions that run until January 14, 2027.

    Source: OpenAI: Introducing Structured Outputs in the API

  4. August 15, 2024

    ChatGPT's own version comes to the API

    The API gained chatgpt-4o-latest, a name that pointed at the GPT-4o then used in ChatGPT and moved when ChatGPT's version changed.

    Source: OpenAI's API changelog

  5. September 24, 2024

    Advanced Voice Mode starts reaching subscribers

    The voice shown in May began rolling out to Plus and Team subscribers in the United States.

    Source: VentureBeat

  6. October 1, 2024

    GPT-4o's voice comes to the API

    The Realtime API opened in public beta on a preview voice model, gpt-4o-realtime-preview.

    Source: OpenAI: Introducing the Realtime API

  7. November 20, 2024

    The November 2024 version arrives on the API

    Its API name is gpt-4o-2024-11-20. It is the other version that runs until January 14, 2027.

    Source: OpenAI's API changelog

2025

  1. March 27, 2025

    ChatGPT's GPT-4o is updated

    OpenAI described the update as more intuitive and better at following instructions. It also became the newest chatgpt-4o-latest on the API.

    Source: ChatGPT release notes

  2. April 25, 2025

    A further update changes how GPT-4o responds

    The update also changed when it saves memories.

    Source: ChatGPT release notes

  3. April 29, 2025

    OpenAI rolls that update back

    OpenAI said the version it removed was overly flattering or agreeable, and that it had given too much weight to short-term thumbs-up and thumbs-down feedback.

    Source: OpenAI: Sycophancy in GPT-4o

  4. August 7, 2025

    GPT-5 replaces GPT-4o as ChatGPT's default

    GPT-5 launched and took the place of GPT-4o and several other models for signed-in users.

    Source: OpenAI: Introducing GPT-5

  5. August 8, 2025

    OpenAI says Plus users can keep GPT-4o

    Sam Altman, OpenAI's chief executive, said Plus users could choose to keep using GPT-4o. By August 11, Plus users could turn it back on in settings, under “Show legacy models”.

    Sources: MacRumors, August 8, 2025, The Register, August 11, 2025, read November 22, 2026

  6. August 12, 2025

    GPT-4o comes back for paid users

    It returned to the model picker for all paid users by default. OpenAI later wrote that it restored GPT-4o after some users asked for more time and said they preferred its conversational style and warmth.

    Sources: ChatGPT release notes, OpenAI: Retiring GPT-4o and older models

  7. November 18, 2025

    OpenAI gives notice for ChatGPT's own version on the API

    Developers were told that chatgpt-4o-latest would leave the API on February 17, 2026.

    Source: OpenAI's deprecations page

2026

  1. January 29, 2026

    OpenAI announces that GPT-4o will leave ChatGPT

    The date was set for February 13, 2026. OpenAI said 0.1 percent of users still chose GPT-4o each day. That is OpenAI's own figure.

    Source: OpenAI: Retiring GPT-4o and older models

  2. February 13, 2026

    GPT-4o leaves ChatGPT

    Business, Enterprise and Edu workspaces kept GPT-4o inside custom GPTs until April 3, 2026.

    Sources: OpenAI: Retiring GPT-4o and older models, OpenAI Help Center

  3. February 17, 2026

    ChatGPT's own version leaves the API

    chatgpt-4o-latest shut down. The dated versions stayed.

    Source: OpenAI's deprecations page

  4. May 7, 2026

    The earlier preview voice models shut down

    gpt-4o-realtime-preview and gpt-4o-audio-preview left the API.

    Source: OpenAI's deprecations page

  5. October 23, 2026

    The May 2024 version shuts down on the API

    gpt-4o-2024-05-13, the first GPT-4o, left OpenAI's API. Microsoft lists January 14, 2027 for this version on Azure, for its own customers.

    Sources: OpenAI's deprecations page, Microsoft's retirement page, read November 22, 2026

  6. December 11, 2026

    Custom GPTs retire in ChatGPT

    This is the date for most accounts. How to save a custom GPT.

    Source: OpenAI Help Center

2027

  1. January 14, 2027

    The last two versions of GPT-4o leave OpenAI's API

    The August 2024 and November 2024 versions shut down. OpenAI names GPT-6 Luna as the replacement. Fine-tuned versions end with them.

    Source: OpenAI's deprecations page

  2. January 20, 2027

    GPT-4o's voice models leave OpenAI's API

    gpt-4o-audio and gpt-4o-realtime shut down. OpenAI gave notice on July 20, 2026.

    Source: OpenAI's deprecations page

  3. February 28, 2027

    Custom GPTs retire for the remaining accounts

    This later date is for FedRAMP workspaces, and Enterprise workspaces with an approved deferral.

    Source: OpenAI Help Center, read November 22, 2026

  4. April 14, 2027

    The same two versions retire on Microsoft Azure

    Microsoft lists this date for the August 2024 and November 2024 versions, for its own customers.

    Source: Microsoft's retirement page, read November 19, 2026
