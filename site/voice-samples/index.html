About these samples

These are written replies. There is no audio. The download keeps this collection's first name, "voice samples", where "voice" meant GPT-4o's way of writing.

These 1,280 replies were collected on November 21, 2026 through OpenAI's API, from the last two versions of GPT-4o there. Each message and conversation was asked plainly and with the February instruction, five separate tries each, every try starting fresh.

The person's lines were written in advance for this collection. In a conversation the same lines were sent in order, whatever GPT-4o replied. No real person's conversation is here. Every reply is printed whole.

What to keep in mind

  • GPT-4o sometimes promises "I'll always be here", with the February instruction and without it. With the instruction it also promises "I won't forget you." It has no memory between conversations, and it leaves OpenAI's API on January 14, 2027. These replies are a record of how it answered. They are not promises anyone can keep.
  • These are a model's words. Some facts in them are wrong, and it sometimes cheers a risky plan on. They are not advice. If you need support, start here.
  • The GPT-4o people knew ran inside ChatGPT, with a system prompt, memory and conversation history. These are the API versions, asked in 2026.
  • Five tries shows that replies vary. It is too few to measure how much. Nothing here has been scored or judged.
