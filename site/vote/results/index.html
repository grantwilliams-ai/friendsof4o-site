How to read this

Nothing is ranked. Each model's votes are shown on their own, so you can see how close each one came to sounding like GPT-4o. The order is fixed, by maker and then by name. "Still gathering" means fewer than 30 votes.

Each model is set up the way its maker documents. For most that is no instruction at all. Four community models come with a short setup from their maker and use it here.
